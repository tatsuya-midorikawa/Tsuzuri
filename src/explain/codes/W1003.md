# Unreachable match arm

## What it covers
Earlier arms of a `match` without a `when` guard already cover every value that this arm matches, so it never runs.

## Fixes
- Delete the arm.
- Move a more specific arm above a general one, such as a wildcard `_` arm.
- Narrow the earlier pattern so that it leaves values for this arm.

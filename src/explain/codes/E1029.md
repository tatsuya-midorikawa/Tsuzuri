# Pure function contract violation

## What it covers
A `pure def`, a pure function type (`pure (T -> U)`), or a pure class method or instance breaks its contract: the body, or a function it reaches, performs IO, calls an extern, reads the clock or a random source, uses shared mutable state, the GPU, or `dyn`; or the signature takes a `mut` parameter, a `ref mut` reference, or an `own` value that is not plain data. An implementation that binds only some parameters of its declared call stage is also reported.

## Fixes
- Move the effect (IO, `Debug.print`, clocks, `Atomic`, `Mutex`, extern calls) into an ordinary `def` that calls the pure function.
- Take inputs as shared references and return a new value instead of writing through `ref mut`.
- Use `own` only for plain data: numbers, strings, collections, and records, unions, or tuples of them.
- Pass a pure callback or a closed function where a pure function type is expected.
- Bind every parameter of the declared call stage, or declare a parenthesized factory result.

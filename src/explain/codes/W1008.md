# Effect attribute that is not checked as written

## What it covers
An effect attribute on a generic function is checked for each instantiation, and the program instantiates the function with no type, so nothing was checked. Or the attribute is on a `const def`, which the compiler evaluates at compile time: only its run-time body is checked.

## Fixes
- Call the generic function, or test it, with the types that you want the attribute to cover.
- Remove the attribute from a `const def` that only runs at compile time.

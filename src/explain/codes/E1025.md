# Deriving error

## What it covers
A `deriving` clause or a `@json` attribute cannot be honoured: a class that cannot be derived, a field or payload that the derived instance cannot handle, a derived `Default` that would never terminate, `@json` on a type that derives neither `Encode` nor `Decode`, or two fields or cases with the same JSON name.

## Fixes
- Derive only `Eq`, `Ord`, `Display`, `Hash`, `Default`, `Encode`, and `Decode`; write an `instance` for other classes.
- Give each field and payload type an instance of the derived class, or write the instance by hand.
- Implement `Default` by hand when the first case of a union is recursive.
- Add `deriving (Encode)` or `deriving (Decode)` before using `@json`, or remove the attribute.
- Give every field and case a distinct JSON name.

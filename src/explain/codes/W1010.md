# Extern function used without `@trusted`

## What it covers
An `extern` function that the program uses has no `@trusted` mark, so nothing records that a person checked its contract. `check`, `build`, `run` and `test` report it with `--warn untrusted-extern` for the root package's declarations; `tsuzuri audit` reports it for every package. An extern function that nothing uses is not reported.

## Fixes
- Check the C function's ABI, ownership and lifetime contract, then add `@trusted` on the line before its declaration, with the properties it has (`@trusted pure`).
- Remove the declaration and its uses if it is not needed.

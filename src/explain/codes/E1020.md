# Invalid pattern

## What it covers
A pattern does not fit the value it matches: a union case with a missing, extra, or wrongly shaped payload pattern, an OR pattern whose sides bind different names, an expression or `null` in a pattern, an array pattern on a fixed-length array, an unknown case or active pattern, and malformed active pattern declarations.

## Fixes
- Match a case that carries a payload with a payload pattern (`Some _`), several values with one tuple pattern (`Case (a, b)`), and a case without a payload by its name alone.
- Bind the same names on both sides of an OR pattern.
- Use a `when` guard for a condition; expressions are allowed in a pattern only as recognizer arguments.
- Index the elements of a fixed-length array instead of destructuring it.
- Start each active pattern case with an uppercase letter, and check the spelling of case names.

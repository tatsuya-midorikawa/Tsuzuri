# Malformed token in the source text

## What it covers
The lexer could not read a token: an unterminated string, block comment, or interpolation hole, an invalid escape, a malformed numeric literal or suffix, a char literal of the wrong length, an invalid format spec, or a character that identifiers do not allow.

## Fixes
- Close every string literal, block comment, and interpolation hole; write a literal brace in an interpolated string as `{{` or `}}`.
- Write a newline inside a string as `\n`, and use only the escapes the language defines.
- Put the digit separator `_` only between digits, and give a hexadecimal or binary literal an integer suffix, not a floating-point one.
- Keep a char literal to one UTF-16 code unit and a utf8char literal to one Unicode scalar; use a string for more.
- Keep an interpolation hole on one line without comments; bind a long expression with `let` first.
- Write a format spec as `[[fill]align][+][width][.precision][type]`; `e` and `f` need a precision, integer formats take none.

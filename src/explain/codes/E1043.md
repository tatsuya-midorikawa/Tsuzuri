# More than one instance candidate fits

## What it covers
Type-class dispatch for `Index`, `IndexMut`, or an operator found two or more matching instances after checking type arguments and literal constraints (`ambiguous_instance_candidates`). Tsuzuri never picks the first declared instance as an implicit default.

## Fixes
- Add a numeric type suffix to an unsuffixed literal key or operand, such as `1i64` or `1i8`.
- Annotate the key, operand, or lambda parameter with a concrete type, such as `\(k: [i64]) -> t[k]`.

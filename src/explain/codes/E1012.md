# Use of a moved value or invalid assignment

## What it covers
Ownership forbids a move or an assignment: using a value after it was moved; moving a non-Copy value out of an array or list element, a reference, a value whose type implements `Drop`, an owned function, or a `let rec` function that borrows it; assigning to a place that cannot be assigned (in edition 2026 any record field or collection element; in edition 2027 a character of a `string`, a computed member such as `.length`, or a field re-initialized after a move); and updating or replacing a `Drop` value.

## Fixes
- Read what you need before the move, or move the value last; the note shows where it moved, also in a previous loop iteration.
- Pass a borrow with `ref name` where the callee accepts one; in edition 2027, declare a parameter `own T` when the function must move its value.
- Borrow elements of arrays and lists, and fields of `Drop` values, with `ref` instead of moving them.
- Edition 2026: assign only to a `let mut` binding and build a new value with `{ value with field = expression }`. Edition 2027: assign a field or element through a `let mut` owner, a `mut T` parameter, or a `ref mut` reference.
- Construct a new value instead of updating a `Drop` value; inside `Drop.drop`, only read or borrow its fields.

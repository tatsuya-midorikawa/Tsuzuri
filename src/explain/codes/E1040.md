# A name that was removed or renamed

## What it covers
The program uses a name that the language had and has no longer, and that nothing in the program defines. The message names what to write instead.

- `removed_task_expression`, `removed_task_type`, `removed_task_api` (TZ12): `task { }`, `Task<T>`, `Task.run`, `Task.parallel`, `Task.parallel_results` and `Task.scope`.
- `removed_async` (TZ13): `Async { }`, `async { }`, `Async<T>`, `Async.Operation`, and `Async.run`, `block_on`, `all`, `all_results`, `sleep`, `now`, `yield`, `start` and `host`. `removed_net_async` (TZ13): the twelve `Net.*_async` functions.
- `renamed_to_data_channel` (TZ03): the channel with `Sender` and `Receiver` ends is `DataChannel`; `Channel` is Go's two-way channel.

A definition of the program with the name (a type, a module, a builder with `@alias async`) is used as before.

## Fixes
- Run `tsuzuri fix`: it writes the `DataChannel` names and replaces `Task.scope` with `Routine.scope`.
- Rewrite the other uses as the help says: run the work directly, or in `tzroutine { ... }` with a `WaitGroup`, an `ErrGroup` or a `Channel`, and call the `Net` functions without `_async` in a tzroutine.
- For the two-way channel, create it with `Channel.make n` (0 is unbuffered), use `Channel.send ch item` and `Channel.recv ch`, and close it with `Channel.close`.

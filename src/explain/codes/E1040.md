# A name that was removed or renamed

## What it covers
The program uses a name that the language had and has no longer, and that nothing in the program defines. The message names what to write instead.

- `removed_task_expression`, `removed_task_type`, `removed_task_api` (TZ12): `task { }`, the type `Task<T>`, and `Task.run`, `Task.parallel`, `Task.parallel_results` and `Task.scope`. Run the work directly, or in `tzroutine { ... }` with a `WaitGroup` or a `Channel`; use `Parallel.init` or `Parallel.map` for data parallelism, `ErrGroup` for the first error, and `Routine.scope` for `Task.scope`. A `Task` that the program defines is used as before.
- `renamed_to_data_channel` (TZ03): the channel with `Sender` and `Receiver` ends is `DataChannel` (`DataChannel.bounded`, `DataChannel.clone_sender`, `DataChannel.Sender`, `DataChannel.Receiver`); `Channel` is Go's two-way channel.

## Fixes
- Run `tsuzuri fix`: it writes the `DataChannel` names and replaces `Task.scope` with `Routine.scope`. Rewrite the other uses of `Task` by hand, as the help says, since their meaning changes.
- For the two-way channel, create it with `Channel.make n` (0 is unbuffered), use `Channel.send ch item` and `Channel.recv ch`, and close it with `Channel.close`.

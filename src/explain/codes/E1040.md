# A name that was removed or renamed

## What it covers
The program uses a name that the language no longer has and that the program does not define. The message names what to write instead.

- `removed_task_expression`, `removed_task_type`, `removed_task_api` (TZ12): `task { }`, `Task<T>`, `Task.run`, `parallel`, `parallel_results` and `scope`.
- `removed_async` (TZ13): `Async { }`, `async { }`, `Async<T>`, `Async.Operation`, and `Async.run`, `block_on`, `all`, `all_results`, `sleep`, `now`, `yield`, `start` and `host`. `removed_net_async` (TZ13): the twelve `Net.*_async` functions.
- `renamed_to_data_channel` (TZ03): the channel with `Sender` and `Receiver` ends is `DataChannel`; `Channel` is Go's two-way channel.
- `renamed_io_function` (E17): `IO.readln`, `writeln`, `write_err`, `write_errln` and their `try_` forms replace `read_line`, `write_line`, `write_error`, `write_error_line` and theirs.

A definition of the program with the name (a type, a module such as `Tools/IO.tz`, a builder with `@alias async`) is used as before.

## Fixes
- Run `tsuzuri fix`: it writes the new `DataChannel` and `IO` names and `Routine.scope` for `Task.scope`.
- Rewrite the other uses as the help says: run the work directly, or in `tzroutine { ... }` with a `WaitGroup`, an `ErrGroup` or a `Channel`, and call the `Net` functions without `_async` in a tzroutine.
- For the two-way channel, use `Channel.make n` (0 is unbuffered), `Channel.send ch item`, `Channel.recv ch` and `Channel.close`.

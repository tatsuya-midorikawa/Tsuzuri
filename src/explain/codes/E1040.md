# A name that was removed or renamed

## What it covers
The program uses a name that the language had before and has no longer, and that nothing else in the program defines. The message says what the name is now, and the fix (`tsuzuri fix`) writes the new name.

- `renamed_to_data_channel`: the channel with separate `Sender` and `Receiver` ends, which was called `Channel`, is `DataChannel` now: `Channel.bounded`, `Channel.clone_sender`, `Channel.Sender` and `Channel.Receiver` are `DataChannel.bounded`, `DataChannel.clone_sender`, `DataChannel.Sender` and `DataChannel.Receiver`, with the same meaning. The name `Channel` is Go's two-way channel (`Channel.make`, `Channel.send`, `Channel.recv`, `Channel.close`).

## Fixes
- Run `tsuzuri fix`, or write the name that the message gives.
- To move to the two-way channel instead, create it with `Channel.make n` (0 is unbuffered), send with `Channel.send ch item` and receive with `Channel.recv ch`; it closes only with `Channel.close`.

# A name that was removed or renamed

## What it covers
The program uses a name that the language no longer has. The message names what to write instead.

- `removed_task_expression`, `removed_task_type`, `removed_task_api` (TZ12): `task { }`, `Task<T>`, `Task.run`, `parallel`, `parallel_results`, `scope`.
- `removed_async` (TZ13): `Async { }`, `async { }`, `Async<T>`, `Async.Operation`, `Async.run`, `block_on`, `all`, `all_results`, `sleep`, `now`, `yield`, `start`, `host`. `removed_net_async`: the twelve `Net.*_async`.
- `renamed_to_data_channel` (TZ03): the channel with `Sender` and `Receiver` ends is `DataChannel`; `Channel` is Go's two-way channel.
- `renamed_io_function` (E17): `IO.readln`, `writeln`, `write_err`, `write_errln` and their `try_` forms replace `read_line`, `write_line`, `write_error`, `write_error_line` and theirs.

Only a module that resolves to the std one counts, also after `std::`. The program's own definitions (a type, a module such as `Tools/Channel.tz`, a builder with `@alias async`) win; a name its module lacks is `E1002`.

## Fixes
- Run `tsuzuri fix`: it writes the new `DataChannel` and `IO` names and `Routine.scope` for `Task.scope`, keeping `std::`.
- Rewrite the other uses as the help says: run the work directly or in `tzroutine { ... }` with a `WaitGroup`, `ErrGroup` or `Channel`; call `Net` without `_async` in a tzroutine.
- The two-way channel: `Channel.make n` (0 is unbuffered), `Channel.send ch item`, `Channel.recv ch`, `Channel.close`.

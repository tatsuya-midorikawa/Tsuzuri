# Spelling that has a canonical form

## What it covers
With `--warn canonical`, a spelling of the root package that edition 2027 rejects: a bare `..` as the last operator of a `for` range, a short numeric suffix (`86uy`), `&x`, `&mut x`, `*r`, `&T` in a type, or a lambda without a backslash (`x -> e`). Each warning carries the rewrite to the canonical form, `certain` when it keeps the meaning and the generated code, and `likely` when the meaning stays the same but the code may differ (`&` of a temporary, a lambda whose parameter is `_`).

## Fixes
- Apply the rewrites with `tsuzuri fix`, or migrate the package with `tsuzuri fix --edition 2027 --from 2026 PATH`.
- `&r` of a reference has no rewrite: `ref r` reborrows `r` instead of borrowing the reference.

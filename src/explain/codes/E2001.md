# File read or write failure

## What it covers
The compiler could not read an input or write an output: a file or directory that does not exist or lacks permission, an input that is not a regular file or not UTF-8, a project directory without `Main.tz`, a temporary directory that cannot be created, or a `TSUZURI_RUNNER` program that cannot start. `tsuzuri serve` uses it for an unsafe socket directory and for a server that is already running or not found.

## Fixes
- Check the path in the message, and that the file exists and is readable.
- Save sources as UTF-8 regular files, not symbolic links or special files.
- Give the output directory write permission and enough free space.
- Set `TSUZURI_RUNNER` to a program that exists on this machine.
- For `tsuzuri serve`, check the server with `--status` or stop it with `--stop`, and point `TSUZURI_SERVER_DIR` at a directory that only you own.

# Misplaced or malformed `@trusted`

## What it covers
`@trusted` marks an `extern` declaration whose ABI, ownership and lifetime contract a person checked. It is written on the line before `extern`, optionally followed on the same line by the properties `pure`, `no_alloc`, `no_copy`, `no_trap` and `terminates`. This error covers `@trusted` before a declaration that is not `extern`, an unknown property, a property listed twice, a property on an `extern type`, and two `@trusted` on one declaration.

## Fixes
- Remove `@trusted`, or declare the function with `extern`.
- Use only `pure`, `no_alloc`, `no_copy`, `no_trap` and `terminates`, each once.
- Write `@trusted` alone before an `extern type`.

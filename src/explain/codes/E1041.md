# An anonymous union is misused

## What it covers
An anonymous union `(A | B)` tells its members apart by their types alone.

- `anonymous_union_type_variable`, `anonymous_union_indistinct_members`, `anonymous_union_duplicate_member`: a member is a type variable, two members are equal for some type arguments (`Maybe<'a>` and `Maybe<i64>`) or differ only in purity, or a member repeats once aliases are expanded.
- `anonymous_union_ambiguous_literal`, `anonymous_union_ambiguous_member`: a value could be two members, as `16` in `(i32 | i64 | string)`. No member is a default.
- `type_test_unknown_scrutinee`, `type_test_not_anonymous_union`: the value that `:?` tests has no known anonymous union type.
- `type_test_not_member`: a type after `:?` is no member of the tested union.
- `type_test_narrow_borrowed`: `:? (A | B) as x` makes a new value, but a member is not Copy and the tested value is borrowed or the arm has a guard.
- `anonymous_union_instance`: an `instance` names an anonymous union.

## Fixes
- Remove the repeated member, or make the members concrete.
- Add a literal suffix such as `16i64`, or annotate the value with a typed `let`.
- Annotate the value that `match` tests with its anonymous union type.
- Test member types only. Give a member that is not Copy its own `:?` arm, or match an owned value without a guard.
- Declare a union with named cases, or wrap the union in a record, when cases hold a type variable or the same type, or need an instance.

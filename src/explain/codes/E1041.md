# An anonymous union whose members cannot be told apart

## What it covers
An anonymous union `(A | B)` tells its members apart by their types alone, so every member must be a distinct type that is known without type arguments.

- `anonymous_union_type_variable`: a member is a type variable such as `'a`, or a type whose head is one. The member could be any type, even another member.
- `anonymous_union_indistinct_members`: two members are equal for some type arguments, as `Maybe<'a>` and `Maybe<i64>` are when `'a` is `i64`.
- `anonymous_union_duplicate_member`: two members are the same type after aliases are expanded and nested anonymous unions are flattened, as `(Meters | f64)` is with `type Meters = f64`.

The location is the anonymous union type as written.

## Fixes
- Remove the repeated member, or the alias that names a member a second time.
- Make the members concrete, such as `Maybe<string>` and `Maybe<i64>`, so that they differ without type arguments.
- Declare a union with named cases, such as `union OrInt<'a> = Value of 'a | Int of i64`, when a case holds a type variable or two cases hold the same type.

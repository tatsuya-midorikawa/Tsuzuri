# Malformed doc example

## What it covers
A ```` ```tsuzuri ```` example in a `///` comment that `tsuzuri test --doc` cannot read: an unknown option after `tsuzuri`, an option given twice or two of `run=`, `test`, `ignore` and `fails=` together, a `fails=` value that is not an error code, a `run=` value with a malformed `%` escape or bytes that are not UTF-8, a fence indented inside the comment, a fence that is not closed, or a fence without code. `tsuzuri test --doc` reports every such fence and runs no example.

## Fixes
- Write the options as `run=OUTPUT`, `test`, `ignore` or `fails=E1012`, at most one of them.
- Encode the output of `run=` with `%20` for a space, `%0A` for a newline, `%25` for `%` and `%60` for a backtick.
- Start the fence at the first column of the comment (`/// ```tsuzuri`), close it with a line of backticks, and put at least one line of code in it.

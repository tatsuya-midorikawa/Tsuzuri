# Wrong number of arguments or parameters

## What it covers
A count of arguments or parameters does not match: a call applies more arguments than the function accepts, a definition's lambda has a different number of parameters from its signature, an instance method or active recognizer takes the wrong number, or `Owned.function` gets a lambda of more than one parameter.

## Fixes
- Pass no more arguments than the function's type accepts; the help gives the count.
- Give the lambda of a definition (`\a b -> ...`) or its `fn name a b =` implementation exactly the parameters of the `def` signature.
- Give an instance method the parameters that its class method declares.
- Give an active recognizer an input parameter, and pass a recognizer the extra arguments it expects.
- Pass `Owned.function` a lambda of one parameter; take a tuple or return another function.

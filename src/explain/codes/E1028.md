# Type class that cannot be dyn

## What it covers
`dyn C` names a class, or a combination of marker classes, that dynamic dispatch does not support. A class can be `dyn` when each method takes the class type as `'a`, `ref 'a`, or `ref mut 'a` in its first parameter and nowhere else; classes without methods, higher-kinded classes, and `Drop` cannot. The message gives the reason.

## Fixes
- Write a generic function with the constraint that the message suggests instead of using `dyn`.
- Change the class so that the class type appears only in the first parameter of each method.
- List `Copy` and `Send` as markers, as in `dyn (C, Copy)`; a `dyn` with a region (`dyn C {r}`) cannot be `Send`.

# Record field error

## What it covers
A record literal, update, or field access names a field that the record does not have, leaves out a field, or reads a field of a value that is not a record.

## Fixes
- Check the field name; for an unknown field, the help lists the record's fields.
- Give every field a value in a record literal; to change only some fields of an existing value, write `{ value with field = expression }`.
- Read fields only from a record; arrays, lists, strings, and utf8strings have only `.length`.
- When a field of the record is near the unknown one, the diagnostic lists it in `candidates` and offers a `maybe` fix when one is closest.

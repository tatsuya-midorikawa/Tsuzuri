# Duplicate name

## What it covers
Two declarations in one scope use the same name, or a declaration uses a reserved name. This covers functions and their signatures, records and their fields (also in a record literal), parameters, members of one `let rec` group, `and!` bindings, extern declarations, classes in `deriving`, and export names, which must be unique across modules.

## Fixes
- Rename one of the two; the note `first defined here` points at the first definition.
- Write each function's signature and definition once; a `def` signature and its `fn` implementation together are one function.
- Give every parameter, record field, `and!` binding, and member of a `let rec` group its own name.
- Keep the names of `export def` functions unique across all modules, because they share the C and WASM symbol namespace.
- Declare each `extern` once, and list each class once in `deriving (...)`.

# Declaration skipped by bindgen

## What it covers
`tsuzuri bindgen` left out a C declaration or integer macro that it could not convert. The message gives the reason, and the output keeps a `// skipped` line for it. Generation continues and the exit code is 0.

## Fixes
- Declare the function by hand with `extern def` in a module of your own.
- Wrap the C function in a C function whose signature uses only supported types, and bind the wrapper.
- Convert a pointer and length parameter pair with `--buffer F:P:L`.

# Numeric literal out of range

## What it covers
A numeric literal cannot be represented in its type: an integer outside the range of its type (including a negative literal of an unsigned type), a floating-point or decimal literal outside its range, a literal used at a type of the wrong kind, or an invalid digit in a bigint literal. Literals never wrap around.

## Fixes
- Choose a type that holds the value, with a type suffix or an annotation such as `let value: i64 = 3000000000`.
- Write a value without a minus sign for an unsigned type, and a bit pattern such as `0xFF00` at an unsigned type (`i16u`).
- Use an integer literal where an integer type is expected, and a floating-point literal where a floating-point type is expected.
- Keep a floating-point literal within its type's range; `1e309` exceeds `f64`.

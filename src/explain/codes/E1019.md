# Missing or misplaced rec

## What it covers
The `rec` and `and` markers do not match the recursion in the program: a function that calls itself, directly or through function values, methods, or operators, lacks `rec`; an `and` has no preceding recursive group; or a signature and its implementation disagree on `rec` or `and`.

## Fixes
- Write `def rec name :: ...` for a function that calls itself.
- Put mutually recursive functions in one group: `def rec` for the first and `and` for each of the others.
- Put `rec` on both the `def` signature and its `fn rec` implementation, or on neither.
- Start an `and` only after a `def rec` or another member of its group.

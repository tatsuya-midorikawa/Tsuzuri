# Spelling that edition 2027 removed

## What it covers
A source read with edition 2027 uses one of the spellings that have a canonical form: a bare `..` as the last operator of a `for` range (write `..=`, or `..<` to exclude the end), a short numeric suffix such as `86uy` or `1.5f` (write the type name, `86i8u`, `1.5f32`), `&x` or `&mut x` (write `ref x`, `ref mut x`), `*r` (write `deref r`), `&T` in a type (write `ref T`), or a lambda without a backslash such as `x -> y -> x + y` (write `\x y -> x + y`). Edition 2026 still accepts them; `--warn canonical` reports them there with their rewrites.

## Fixes
- Write the canonical form that the message names.
- Migrate a 2026 package with `tsuzuri fix --edition 2027 --from 2026 PATH`, which applies the `certain` rewrites first.
- `&r` of a reference `r` borrows the reference itself, which `ref r` does not say; pass `r` itself, or keep the package on edition 2026.

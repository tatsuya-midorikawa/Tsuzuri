# Invalid command line or build configuration

## What it covers
A command's arguments, options, or environment are not valid: an unknown or repeated option, a missing input or one with the wrong extension, options that conflict or need another option, an unknown `--target`, an environment variable such as `TSUZURI_STRINGS` with an unsupported value, or a target or output kind that cannot build what the program uses. `tsuzuri fmt --check` reports an unformatted file with this code too.

## Fixes
- Run `tsuzuri --help` and check the command's synopsis and the spelling of each option.
- Pass a `.tz`, `.tt`, or `.tc` file, or a project directory, as the input.
- Remove one of two conflicting options, or add the option that the message says is required.
- Choose a target from the supported list; to run a program for another platform, set `TSUZURI_RUNNER` to a command that runs it.
- Set environment variables to one of the values that the message lists, or unset them.
- Run `tsuzuri fmt` on the files that `tsuzuri fmt --check` reports.

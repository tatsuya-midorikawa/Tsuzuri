# Unused local

## What it covers
A local binding, parameter, or pattern binding is never used, or a local `let rec` function is used only inside its own body. Moves, borrows, guards, and closure captures count as uses. Standard library internals and bindings that the compiler creates are not reported.

## Fixes
- Remove the binding if nothing needs it.
- Name it `_`, or give it a `_` prefix such as `_unused`, to keep it and silence the warning.
- Check for a misspelled later use that was meant to read this binding.
- Apply the editor's quick fix, which adds the `_` prefix.

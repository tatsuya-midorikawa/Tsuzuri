# Knowledge graph missing, stale, or broken

## What it covers
A `tsuzuri kg` command could not read or place the project's knowledge graph (`target/tz/kg`): there is none, it was written for other sources or another compiler, a file is missing, does not match `manifest.json`, or breaks the graph's invariants, the directory is not a graph that the compiler wrote (no `.tsuzuri-kg` marker) or holds the project's sources, or the project did not type-check when the graph was written. `check`, `build`, `run` and `test` never report it: a graph that they cannot write is one `W2001` warning.

## Fixes
- Build the graph with `tsuzuri check` or `tsuzuri kg build`.
- Rebuild a stale or broken graph with `tsuzuri kg build --force`.
- Fix the errors that `tsuzuri check` reports, then build the graph again.
- Choose another directory with `--kg-dir DIR` when the directory belongs to something else.

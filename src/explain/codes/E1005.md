# Invalid call, operation, or capture

## What it covers
An operation does not apply to its operand: calling a value that is not a function, a missing type class instance for an operator or function, indexing, slicing, dereferencing, or iterating a value that does not support it, a parameter convention in the wrong place, or a function value that captures what it cannot carry (an exclusive borrow, an `Rc`, an `Atomic` or `Mutex`, or a generic value in a `let rec`).

## Fixes
- Call only function values; remove the arguments after a value that is not a function.
- Define an instance for the type, or use a type that already has one.
- Iterate arrays, lists, strings, utf8strings, integer ranges, or `Seq` with `for ... in`; call `Module.iter` for your own types.
- Capture an `Arc` instead of an `Rc`, borrow an `Atomic` or `Mutex`, or pass the value as an argument.
- Write `own` and `mut` only on parameter types of a `def` signature; `mut T` parameters need edition 2027.
- Slice only a named array; index a fixed-length array instead of iterating or exclusively slicing it.

# Output protected from overwrite

## What it covers
The compiler refused to write an output that could damage existing files: an output path that is an input source, a link input, a symbolic link, a directory, or a special file, or that has a source extension; a `tsuzuri doc` or `tsuzuri bindgen` output that the tool did not create; or a source that changed while `tsuzuri fmt` formatted it. A publication that failed and could not be restored is reported too.

## Fixes
- Choose a different `-o` path that is not an input, a link input, a symbolic link, or a directory.
- Give outputs a name without the `.tz`, `.tt`, or `.tc` extension.
- Write `tsuzuri doc` output to a new or empty directory outside the project sources; it reuses only a directory with its `.tsuzuri-docs` marker.
- Delete a file that `tsuzuri bindgen` did not generate, or choose another output.
- Run `tsuzuri fmt` again once no other program is writing the file.
- After a failed publication, recover the files from the directory that the message names.

# Ambiguous, infinite, or ill-kinded type

## What it covers
Type inference cannot finish: a polymorphic use whose type is not determined, an infinite type, a type constructor used at the wrong kind or not fully applied, a constraint on a type variable that is not in the signature, or a place that needs a concrete type (an entry point, an extern signature, `Dyn.of`, a SIMD operation). Messages that start with `internal compiler error` also use this code.

## Fixes
- Add a type annotation to the binding, parameter, or result so that the type is concrete.
- Put a constraint only on a type variable that appears in the signature.
- Apply a type constructor to all of its type arguments in a value type.
- Give `Dyn.of` an expected `dyn` type, for example through an annotated `let`.
- Report an `internal compiler error` with the program that causes it.

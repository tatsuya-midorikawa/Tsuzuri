# Ambiguous or unresolved type name

## What it covers
A name does not resolve to exactly one declaration: a type, type class, or union that does not exist, a name that several `using` declarations or builders make visible, a type with the wrong number of type arguments, a length where a type belongs (or the reverse), or an empty collection whose element type is unknown.

## Fixes
- Qualify an ambiguous name with its namespace or module, or rename one of the declarations.
- Check the spelling of a type name or declare it, and join namespaces and modules with `::`.
- Give a generic type the number of type arguments it declares, written in `<...>`.
- Annotate an empty array or list with its element type.
- Put a length only in `[T; N]` or a length parameter, and a type only where a type is expected.

# Implicit copy of an array or list

## What it covers
An array or list is deep-copied implicitly, for example when it is bound to another name. The warning appears only with `--warn implicit-copy`, once per source position; the generated code is the same with or without the flag.

## Fixes
- Borrow the value with `ref` instead of copying it.
- Call `Array.copy` or `List.copy` to make the copy explicit.

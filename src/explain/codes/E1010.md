# Type layout limit

## What it covers
The memory layout of a value type cannot be built: a fixed-length array is too long, records or unions nest beyond the limit, a value is larger than the size limit, or a recursive type has no finite value.

## Fixes
- Use an array `[T]` instead of a very long fixed-length array `[T; N]`.
- Make a recursive type pass through a union with a base case, or an empty collection alternative, so that a value can be finite.
- Flatten deeply nested records or unions, and use smaller value types for very large values.

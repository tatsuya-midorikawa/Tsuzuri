# Contract line error

## What it covers
A `@requires` or `@ensures` line is wrong: it is not at the start of a top-level function body, it is on a `const def`, its condition is not `bool` or not pure, `@ensures` does not name the result with a lambda, the result holds a reference, or `@old` is misused (outside `@ensures`, nested, reading the result, or of a value that is not a plain Copy value).

## Fixes
- Put the contract lines on their own lines right after `=` or `->`, before the first statement of the body.
- Write a `bool` condition such as `x > 0`, and call only pure functions in it.
- Write `@ensures \r -> condition` to name the result, or `@ensures \_ -> condition` for a line about the arguments.
- Return an owned value instead of a reference when an `@ensures` line needs the result.
- Use `@old (expression)` only inside `@ensures`, on a number, a bool, or a field of one.

# Misplaced effect attribute

## What it covers
An effect attribute (`@no_alloc`, `@no_copy`, `@no_trap`, `@terminates`) is written where it does not apply: before something other than the `def` signature of a top-level function, twice on one declaration, before an `extern` function, which has no body to check, or in an expression.

## Fixes
- Put the attribute on the line before the function's `def` signature; its `fn` or `let` implementation follows the signature's attributes.
- Write each attribute once.
- Remove the attribute from an `extern` declaration.

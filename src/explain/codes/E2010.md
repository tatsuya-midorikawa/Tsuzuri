# MCP server stopped

## What it covers
`tsuzuri mcp` stopped: the project root of `--root` (or the current directory) is not a directory it can use, it could not read its client's input or write its answers, or it could not start its worker thread. Mistakes in the client's messages are not this error: the server answers them with JSON-RPC errors and keeps running.

## Fixes
- Pass an existing project directory with `--root DIR`.
- Check that the client keeps the server's standard input and output open while it runs.
- Start the server again; if the worker thread cannot start, free memory or lower `TSUZURI_THREADS` for the other processes.

# Unknown name

## What it covers
A value, function, constant, union case, module member, or type class method is used but not declared where the use can see it.

## Fixes
- Check the spelling; for an unknown value, the message lists the locals that are in scope.
- Write a name from another module as `Module.name`, and check that the module defines it (`String.length`, not `String.len`).
- Declare a local before the line that uses it; a local function that calls itself needs `let rec`.
- Use a case that the union declares, or a method that the type class declares.
- Write a length in `[T; N]` as an integer literal, an `i64` constant, or a length parameter.
- When a declared name is near the unknown one, the diagnostic lists it in `candidates` (a name that only needs its module, as `Array.length` for `length`, too) and offers a `maybe` fix when one is closest.

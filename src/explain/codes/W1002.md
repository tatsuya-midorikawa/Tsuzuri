# Unused private declaration

## What it covers
A `private` function, record, union, or type alias is not reachable from the module's public API, so nothing can use it.

## Fixes
- Delete the declaration if it is no longer needed.
- Remove `private` if other modules should use it.
- Use it from a public declaration of the module, if that was the intent.

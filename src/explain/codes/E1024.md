# Type parameter, union, or alias declaration error

## What it covers
A type declaration is malformed: duplicate type parameters or union cases, a type alias or union case name that does not start with an uppercase letter, a cyclic type alias, alias parameters that are undeclared or unused, or an alias given the wrong number of type arguments.

## Fixes
- Give each type parameter and union case a distinct name; the note shows the first definition of a case.
- Start type alias names and union case names with an uppercase ASCII letter; lowercase names in patterns bind variables.
- Remove the recursive reference from a type alias; declare a record or union for a recursive type.
- Declare every type variable and length (`const N: i64`) that an alias uses, and remove the ones it does not use.
- Give an alias as many type arguments as it declares, in `<...>`.

# Type class or instance error

## What it covers
A type class or instance declaration breaks a rule: an unknown class, an instance that lacks a method or defines an unknown one, overlapping instances, a built-in instance redefined, a class method with its own constraints or another type variable, a missing explicit `#name` constraint, and `Drop` or `Format` instances outside their rules. Calling `Drop.drop` directly is also reported.

## Fixes
- Check the class name, and qualify it with its module when needed.
- Implement every method that the class declares, and no others.
- Keep one instance per class and type; remove overlapping instances.
- Implement `Drop` and `Format` only for records and unions declared in this program; a `Drop` instance covers every instantiation without constraints.
- Let a value go out of scope instead of calling `Drop.drop`.
- Put constraints on the functions that use a type, not on its fields; write the `@'T : #name` constraint that the message asks for.

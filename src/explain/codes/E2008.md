# Edition migration failure

## What it covers
`tsuzuri fix --edition YEAR` could not migrate a package or file: the target edition is older than the current one, `--from` disagrees with the package manifest, a rewritten source would exceed the size limit, an edit or the update of the manifest's `edition` could not be applied and verified, or writing a file failed. After a write failure, the files already replaced are restored; the message names any that could not be.

## Fixes
- Migrate forward only: pass an `--edition` that is not older than the current edition.
- Omit `--from` for a package, or make it equal to the manifest's `edition`; use `--from 2026` for an input without a manifest.
- Preview the changes with `--dry-run` before writing them.
- Split a source file that would grow beyond the size limit, then migrate again.
- Check file permissions and free space, and restore by hand any file that the message says was not rolled back.

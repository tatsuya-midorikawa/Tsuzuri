# Fix or edition migration failure

## What it covers
`tsuzuri fix` stopped without changing a file: applying the fixes would add a diagnostic, a file changed while it was being fixed, or a file could not be replaced (the earlier replacements are restored). `tsuzuri fix --edition YEAR` could not migrate: the target edition is older, `--from` disagrees with the manifest, a rewritten source would be too large, or the manifest's `edition` could not be updated.

## Fixes
- Review the fixes with `tsuzuri check PATH --json` (the `fixes` of each diagnostic; `tsuzuri fix --dry-run` verifies them too and stops the same way), apply the safe ones by hand, and run `tsuzuri fix` again.
- Rerun after a file changed during the run, once no other tool is writing to it.
- Migrate forward only: pass an `--edition` that is not older than the current edition.
- Omit `--from` for a package, or make it equal to the manifest's `edition`; use `--from 2026` for an input without a manifest.
- Check file permissions, and restore by hand any file that the message says was not restored.

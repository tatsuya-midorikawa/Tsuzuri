# Source file too large

## What it covers
A source file, or the accumulated input of a REPL session, is larger than the 4 MiB limit for one source. The compiler stops before it reads the tokens.

## Fixes
- Split the program into several modules: each `.tz` file is one module named after its filename.
- Move large data out of the source and read it at run time, for example from a file.
- In `tsuzuri repl`, run `:reset` to drop the accumulated input.

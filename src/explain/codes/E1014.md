# Borrow conflict or mutation without permission

## What it covers
An access breaks the borrowing rules: moving, assigning, or exclusively borrowing a place while a borrow of it is still used, mutating a binding declared without `mut`, mutating or exclusively reborrowing through a shared reference, replacing an exclusive slice as a whole, or an active recognizer that mutates its input.

## Fixes
- End the borrow's last use before the conflicting access; the notes show where it was borrowed and where it is still used.
- Declare the binding with `let mut` before assigning to it or borrowing it with `ref mut`.
- Take an exclusive reference (`ref mut T`) instead of a shared one (`ref T`) where the function writes through it.
- Write the elements of an exclusive slice with `Array.write`, or replace the array through its owner.
- Bind an array with `let mut` before slicing it exclusively.

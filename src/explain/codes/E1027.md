# Instance context or superclass constraint error

## What it covers
The constraints around a class or instance do not hold: an instance does not satisfy its class's superclasses, an instance or default method needs a constraint that is not declared, a context mentions a type variable that is not in the instance head or names something that is not a class, or superclasses form a cycle.

## Fixes
- Add the missing constraint to the instance context, or add the superclass instance for the type.
- Declare a constraint that a default method needs as a superclass of the class.
- Use only type variables of the instance head in its context.
- Mention only the class type variable in superclass constraints, and break superclass cycles.
- Check that each name in a context is a type class.

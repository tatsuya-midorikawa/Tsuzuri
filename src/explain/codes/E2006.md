# Failing tests

## What it covers
`tsuzuri test` ran the tests and at least one failed. The diagnostic points at the first failure, its message counts the failures (`2 tests failed`), and the exit code is 1. `tsuzuri test --doc` reports a failed doc example the same way, at the opening fence of the first one (`1 doc test failed`).

## Fixes
- Read each failing test's result line on standard output, and fix the test or the code it checks.
- Run only the failing test with `--filter TEXT`, or with `--index N` using a number from `--list`.
- Build one test with `tsuzuri test DIR --index N -g -o PATH` and start it under a debugger.
- Reproduce a property test failure with the seed it prints, passed as `--seed N`.
- For a doc example, read its `failure:` line: fix the example's `run=` output or code, or the function it shows.

# Contract line that checks nothing

## What it covers
A contract line is always true (`@requires true`), an `@ensures` line names the result but never uses it, or `tsuzuri test --contracts test` cannot generate a property test for a function, because it is generic, has no parameters, has a parameter without a generator, or names the result differently in its `@ensures` lines.

## Fixes
- Remove the line, or state a real condition.
- Write `@ensures \_ -> condition` for a line about the arguments only.
- Give the parameter a type with a generator (numbers, `bool`, `string`, arrays, tuples, `Maybe`, or a type that derives `Arbitrary` and `Display`), or test the function by hand.

# Syntax error

## What it covers
The parser found source that does not fit the grammar: a missing or unexpected token, a function without a `def` signature, a misplaced modifier or attribute (`const`, `mut`, `@cpu`, `@json`, `@checked`), an invalid local `let rec`, nesting deeper than the parser's limit, or invalid syntax, keys, or `edition` in `Tsuzuri.toml`.

## Fixes
- Read what the message expected at the reported position (for example `expected an expression`), and look just before it for an unclosed bracket or a missing operand.
- Declare a function with `def name :: Type`, using `::` between the name and its type, and define it with `= \x -> ...` or a separate `fn name x = ...`.
- Put `const` on the `def` signature only; its `fn`, `let`, or `and` implementation inherits it.
- Bind a lambda in a local `let rec`, and do not combine it with `mut`, `let!`, or `@checked`.
- Give every `match` at least one `| pattern -> expression` arm.
- Split deep nesting with `let` bindings; in `Tsuzuri.toml`, use only known keys and a supported `edition`.

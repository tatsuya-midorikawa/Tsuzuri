# Missing or invalid entry point

## What it covers
The program's entry point does not fit the output: an executable without `Main.tz`, a WASM module without an export or `main`, a library or bindings without `export def`, a WGSL or SPIR-V output without exactly one export, a `main` with the wrong signature, top-level code together with `def main`, or top-level code outside `Main.tz`.

## Fixes
- Pass `Main.tz` or its directory to build an application, or use `--emit object` for a library.
- Declare `def main :: unit -> i32` or `def main :: Array<string> -> i32`; its result is the exit code.
- Use either top-level code or `def main` in `Main.tz`, not both.
- Keep top-level code in `Main.tz`; other modules contain only declarations.
- End top-level code with `IO<T>`, a number, `bool`, `char`, `utf8char`, `unit`, `string`, or `utf8string`.
- Give a WGSL or SPIR-V project exactly one exported kernel.

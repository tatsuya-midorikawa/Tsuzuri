# Break or continue outside a loop

## What it covers
A `break` or `continue` has no enclosing `for` or `while` loop in the same function, task, or computation, or it would leave a `try` whose `finally` must run first.

## Fixes
- Use `break` and `continue` only inside a `for` or `while` loop of the same function.
- Inside a lambda, task, or computation expression, return a value and let the enclosing loop act on it.
- Put the whole loop inside a `try` with a `finally`, or record the outcome in the `try` and break after it.

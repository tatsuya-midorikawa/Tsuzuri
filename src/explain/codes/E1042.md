# An index window needs `ref` or is not writable

## What it covers
An `Index` expression whose result borrows its base (such as a `Tensor.View` or `MatrixView`) must be written with `ref`, just like an array slice `ref xs[a..<b]`.

- `index_view_requires_ref`: an index expression returns a type that borrows its base, such as `Tensor.View<T>`, without a covering `ref`.
- `index_view_not_writable`: `ref mut` covers an index expression whose `Index` instance produces a shared borrow rather than a writable view.

## Fixes
- Write `ref` before the index expression (for example, `ref t[[Slice.range 1 3]]` or `(ref t[[Slice.at 2]])[[3]]`).
- Replace `ref mut` with `ref` when taking a read-only window, or use `Tensor.borrow_mut` / `MatrixView.of_array_mut` when mutating elements through `IndexMut`.

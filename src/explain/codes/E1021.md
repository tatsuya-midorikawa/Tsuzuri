# Match that does not cover every case

## What it covers
A `match` or a function guard does not handle every value of the matched type. The message lists the missing cases; arms with a `when` guard do not count toward coverage.

## Fixes
- Add an arm for each missing case that the message lists.
- End the match with a wildcard arm `| _ -> ...` when the remaining cases share one result.
- Add an arm without a guard after the guarded arms of a case.
- Apply the suggested fix (a quick fix in the editor), which appends the missing arms when there are at most 8 of them.

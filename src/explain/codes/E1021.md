# Match that does not cover every case

## What it covers
A `match` or a function guard does not handle every value of the matched type, or a single-pattern destructuring binding (`let`, a lambda parameter, `for...in`, or a computation binding in edition 2027) is refutable. The message lists a missing case; arms with a `when` guard do not count toward coverage.

## Fixes
- Add an arm for each missing case that the message lists, or end the `match` with a wildcard arm `| _ -> ...`.
- For a refutable binding pattern, bind the value to a name and use `match` (or function guards `| <pattern> -> ... | _ -> ...` on a lambda) to handle the missing cases.
- Apply the suggested fix on an explicit `match`, which appends the missing arms when there are at most 8 of them.

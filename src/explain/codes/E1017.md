# Compiler resource limit exceeded

## What it covers
The program exceeds a fixed limit of the compiler: the size or depth of an analysis (exhaustiveness, instance resolution, specialization, pure checks, loops, regions, deriving), the length of names and paths, or the size of manifests, lockfiles, package graphs, and fetched dependencies. The message names the limit.

## Fixes
- Split a large `match`, function, `try`, or loop body into smaller functions.
- Make a recursive generic call use the same type arguments, so that the types do not grow without bound.
- Simplify long chains of type aliases, instance constraints, or superclasses.
- Shorten namespaces, module paths, and qualified names to the segment limits in the message.
- Reduce the number of dependencies, or the size of a dependency, a manifest, or `Tsuzuri.lock`.

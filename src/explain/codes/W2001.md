# Tool notice

## What it covers
A notice about the tool rather than the source: a build cache that could not be used, profile data that does not match the build, or a `run --profile-generate` that wrote no profile. The command still succeeds; with `--json`, the notice is a warning line with this code. With `run --overflow-report --json`, each report of integer arithmetic that wrapped (`integer_overflow_wrapped`) is a warning line with this code, whose `path` and `span` are the operation.

## Fixes
- For a cache notice, make the cache directory writable or set `TSUZURI_CACHE_DIR` to one; the build works without the cache.
- For a profile mismatch, rebuild with `--profile-generate`, rerun the training workload, and build again with `--profile-use`.
- When no profile was written, check that the directory is writable and let the program end normally; a program that traps or is killed writes none.
- When arithmetic wrapped on purpose (a hash, a random number), write it with `Int.wrapping_add`, `Int.wrapping_sub`, `Int.wrapping_mul` or `Int.wrapping_neg`; otherwise fix the arithmetic or widen the type.

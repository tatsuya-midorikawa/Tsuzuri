# Tool notice

## What it covers
A notice about the tool rather than the source: a build cache that could not be used, profile data that does not match the build, or a `run --profile-generate` that wrote no profile. The command still succeeds; with `--json`, the notice is a warning line with this code.

## Fixes
- For a cache notice, make the cache directory writable or set `TSUZURI_CACHE_DIR` to one; the build works without the cache.
- For a profile mismatch, rebuild with `--profile-generate`, rerun the training workload, and build again with `--profile-use`.
- When no profile was written, check that the directory is writable and let the program end normally; a program that traps or is killed writes none.

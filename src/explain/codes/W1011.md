# Unchecked `Maybe` or `Result` unwrap

## What it covers
Root-package user code outside `test` and `bench` bodies calls or references `Maybe.get`, `Result.get`, or `Result.get_error` from the standard library, which trap when the value is `None`, `Error`, or `Ok`. `check`, `build`, `run`, `test`, and `script` report `W1011` when `--warn unwrap` is enabled.

## Fixes
- Match on the `Maybe` or `Result` explicitly so every case is handled in the type system.
- Use `Maybe.default_value`, `Maybe.default_with`, `Result.default_value`, or a computation expression (`Maybe { let! ... }` / `Result { let! ... }`).

# Use of a deprecated declaration

## What it covers
Code uses a `def`, `record`, or `union` that another package or the standard library marked `@deprecated`. Uses inside the declaring package are not reported. The warning is on by default, and `--deny-warnings` turns it into a failing exit code.

## Fixes
- Switch to the replacement that the message names.
- When the message names no replacement, read the declaration's documentation for one.

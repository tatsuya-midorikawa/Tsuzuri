# 値、可変束縛、コンパイル時定数

[ドキュメントのトップ](../README.md)

値の名前付けには `let`、ローカルな置換可能状態には `let mut`、コンパイル時の評価には `const` を使います。これらは互換の構文ではなく、評価時期と所有権の異なる仕組みです。

## let

```tsuzuri run=42
let count = 40
let increment: i64 = 2
count + increment
```

ローカルな値は型推論され、必要なら `let name: Type = expression` と注釈を付けます。`let` は束縛を書き換えられないことを意味し、定数式だけを受け付けるという意味ではありません。関数呼び出しの結果や実行時に確保した配列も束縛できます。

トップレベルの通常の `let` は入口の `Main.tz` に置きます。一方、先行する `def` に対応する `let name = value -> ...` は関数実装であり、他のモジュールでも使用できます。

## let mut と代入

```tsuzuri run=42
let mut total: i64 = 0
for value in [20, 22] do
    total = total + value
total
```

代入は `=`、等値比較は `==` です。F# の `mutable` / `<-` とは異なります。代入式の結果は `unit` で、束縛の型自体は変えられません。

可変なのはローカルな束縛です。配列要素やレコードフィールドを自由に書き換えられるようになるわけではありません。所有する値全体を別の値へ置換し、古い所有値を必要に応じて解放します。関数を通じて置換するには排他的な借用を使います。

匿名関数に外側の可変束縛を捕捉しても、その束縛の共有可変状態は作られません。捕捉した束縛は不変のスナップショットとして扱われます。

## const の宣言

```tsuzuri run=42
const Answer: i64 = Base + 2
const Base: i64 = 40
const Table: [i64] = [20, 22]

def main :: i64
fn main = Answer
```

定数は明示的な具体型を持ちます。前方参照が可能で、使用されない定数も検査・評価されます。`.tz` と `.tc` に宣言でき、`.tt` には置けません。

既定では公開され、他モジュールからは `Module.Answer` と参照します。`private const` は宣言モジュール内だけで利用できます。関数と同じ値の名前空間を使うため、同名の関数は定義できません。

## 定数式に使えるもの

| 分類 | 対応 |
| --- | --- |
| データ | 数値、真偽値、文字、文字列、配列、タプル、レコード、他の定数 |
| 計算 | 対応する単項・二項演算、`if`、数値の `as` 変換 |
| 短絡 | `if` / `&&` / `\|\|` は選択された式だけを評価 |
| 関数 | 通常関数、型クラスメソッド、ホスト関数の呼び出しは不可 |
| 実行時構造 | list、`new`、索引、フィールド投影、ループ、`match`、lambda、task、借用、代入は不可 |

`if` の両分岐は型検査しますが、未選択の分岐は評価しません。定数参照の循環や未対応式、整数のゼロ除算、符号付き最小値を `-1` で割る操作は `E1026` です。

整数演算は型幅に従って折り返し、シフト量をマスクします。binary 浮動小数点の演算はその型で最近接・偶数丸めされ、NaN、符号付きゼロ、subnormal を保持します。浮動小数点から整数への変換は実行時と同じ切り捨てと飽和です。

decimal 定数はリテラル、符号、恒等変換だけに対応します。decimal の演算・比較・形式間変換を定数評価できるわけではありません。

## 定数と所有権

定数参照は、その場所に評価済みの値を生成します。定数の文字列や配列を全呼び出しで共有する仕組みではありません。定数に特別な static lifetime はありません。

```tsuzuri run=5
const Greeting: string = "hello"
let text = Greeting
String.length ref text
```

所有値を変数に束縛した後は、通常の move と借用の規則が適用されます。定数そのものの一時借用は、借用を返さない単一段階の完全適用中に限られます。参照の保存や返却には、上の例のように所有者を束縛してください。

## 評価の上限

定数依存は深さ 128、一回の探索で 1,024 定数までです。評価と展開は最大 1,048,576 ノードで、超過は `E1026` になります。大規模なデータ生成を定数評価へ無制限に押し込む用途には向きません。

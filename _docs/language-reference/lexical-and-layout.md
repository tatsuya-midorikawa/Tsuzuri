# ソース、識別子、インデント

[ドキュメントのトップ](../README.md)

Tsuzuri のソースは UTF-8 のテキストです。空白で関数を適用し、インデントまたは波括弧で式の本体を表します。見た目が似ていても、F# の字句規則をそのまま適用することはできません。

## ファイルの種類

| 拡張子 | 内容 |
| --- | --- |
| `.tz` | レコード、union、型別名、定数、関数、インスタンス、テスト。入口の `Main.tz` ではトップレベル実行も可能 |
| `.tt` | 型クラスの宣言とデフォルトメソッド。一つのファイルに複数のクラスを置ける |
| `.tc` | ファイル名を名前とする一つのコンピュテーション式ビルダーと補助宣言 |

旧 `.tzr` は直接入力として受理されません。コードは `.tz`、型クラスは `.tt` に分けます。ファイルの探索方法は[言語仕様のモジュール規則](../../docs/language.md#1-ファイル--1-モジュール)を参照してください。

## 識別子

識別子の先頭は ASCII の英字または `_`、後続は英数字または `_` です。大文字小文字を区別します。文字列には日本語を書けますが、日本語の変数名は使えません。

関数とローカル変数には `calculate_total` のような snake_case を推奨します。型やモジュールには `Point` のような名前を使うと読み分けやすくなります。これは命名規則の推奨で、関数名を小文字に限定する構文規則ではありません。

`_` はパターンのワイルドカードです。`_unused` のようなローカル名は意図的な未使用を表せます。型変数は `'a`、`'value` のように書き、匿名の型変数 `'_` は認めません。

## 予約語

```text
fn fx def rec and export extern private record union type const test
class instance deriving let task do return yield for in to downto
while break continue mut ref deref new as if then elif else match
with when true false
```

`of` は union の case 宣言内でだけ特別な意味を持つ文脈キーワードです。`union` は例外としてモジュール関数名とドットの後の名前にも使えます。これは `Set.union` を呼ぶための規則で、変数名や型名への一般的な使用許可ではありません。

`Task` は組み込みの型と名前空間です。標準ライブラリ用の名前空間にも予約があります。予約語と、標準ライブラリのモジュール名の予約は別の規則です。

## コメント

`//` は行末までのコメント、`/* ... */` は入れ子可能なブロックコメントです。通常のコメントは実行にも API 文書にも影響しません。

`///` は直後の API 宣言に結び付くドキュメントコメントです。`fn` の実装ではなく、`def` や型宣言の前に置きます。適用対象以外に置くとエラーになります。これは XML コメントではなく Markdown の説明文です。

## インデント本体

```tsuzuri run=42
def answer :: i64 -> i64
fn answer base =
    let increment = 2
    let result = base + increment
    result

answer 40
```

`=`、`then`、`do`、`->` の後に複数行の本体を置く場合、最初の式の深さが本体の基準です。より浅いインデントで本体が終わります。整形ツールは 4 スペースを使います。

本体の最後の式が結果です。途中に結果を捨てる式を書く場合、その型は `unit` でなければなりません。戻り値が不要な関数には、その契約を明示します。

## 明示ブロック

```tsuzuri run=42
def answer :: i64
fn answer = {
    let base = 40;
    let increment = 2;
    base + increment
}

answer()
```

波括弧で囲むとき、`let` の区切りには `;` を使います。インデント本体の改行区切りと混同しないでください。

## 空白に意味がある場所

| 表記 | 意味 |
| --- | --- |
| `transform value` | 一つの引数を関数へ適用 |
| `transform (left + right)` | 括弧内の計算結果を引数にする |
| `transform (-1)` | 負の値を引数にする |
| `values[index]` | 添字アクセス |
| `transform [1, 2]` | 配列を引数にする |
| `transform value.field` | フィールドを取り出してから適用 |
| `(transform value).field` | 適用した結果のフィールドへアクセス |
| `left * right` | 乗算 |
| `transform *reference` | 参照外しした値を引数にする互換表記 |

空白による関数適用は改行をまたぎません。引数列を無造作に次行へ移さず、括弧内や演算子の直後など、式を継続できる位置で改行します。

## 入力の制限

先頭 BOM、LF、CRLF を受理します。一つのソースファイルは最大 1 MiB、構文と式の深さは最大 128 です。深い式はローカルな `let` に分けます。上限は安全なコンパイルのためのもので、実行時の配列長を 128 に制限するものではありません。

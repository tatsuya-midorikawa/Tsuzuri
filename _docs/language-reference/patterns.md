# パターンマッチ、網羅性、関数ガード

[ドキュメントのトップ](../README.md)

`match` は入力の形に応じて値を計算します。対象を一度だけ評価し、上から順に最初に成立する節を選びます。すべての結果式は同じ型です。

## match と when

```tsuzuri run=42
def classify :: i64 -> i64 = \value ->
    match value with
    | 0 | 1 -> 0
    | larger when larger > 100 -> larger - 100
    | _ -> 42

classify 142
```

`when` の条件は、その節のパターンが成立した後にだけ一度評価します。false なら次の節へ進みます。ガード中の束縛は読み取り専用で、失敗した後に入力を失わないように検査します。

## パターン一覧

| パターン | 用途 |
| --- | --- |
| `42`, `true`, `"text"`, `()` | 定数との比較 |
| `value` | 値を名前へ束縛 |
| `_`, `otherwise` | 値を束縛せず任意の入力に一致 |
| `(left, right)` | タプルの分解 |
| `Point { horizontal: value }` | 名前付きレコードの一部または全フィールド |
| `{ horizontal = value; vertical = 0 }` | フィールドによるレコードパターン |
| `Some value`, `Result.Error error` | union の case と payload |
| `[left, right]` | ちょうど二要素の配列 |
| `[\|left, right\|]`, `[\|\|]` | リストの固定長または空 |
| `head :: tail` | 空でないリストの先頭と残り |
| `first \| second`, `first & second` | OR、AND |
| `pattern as whole` | 一致した全体も束縛 |
| `(pattern: Type)` | パターンの型注釈 |

OR の両側は同じ名前と型を束縛しなければなりません。左側で一致してガードが false になった場合、同じ OR の右側でガードを再試行せず、次の節へ進みます。

同一行の `|` は節や OR の区切りです。ガードや結果でビット OR を使う場合は括弧で囲みます。

## リストの分解

```tsuzuri run=42
let values = [|40, 10, 20|]
match ref values with
| [||] -> 0
| first :: remaining -> first + remaining.length
```

所有する tail が必要になると Copy 要素と独立したノード列の複製を要求する場合があります。長いリストを集計するときは、tail を繰り返し複製する再帰より直接の for 走査を使うと O(n) で処理できます。

## 網羅性

bool、unit、union、リストの空と先頭・tail、およびタプル・レコードの組み合わせを検査します。一致しない値があれば `E1021` となり、不足する値の例を診断に含めます。

整数や文字列の定数を多数列挙しても、一般に網羅とはみなしません。i8 の全値を列挙した場合にも `_` などの節が必要です。配列長の列挙も同様です。

ガード付きの節は false になり得るので網羅には数えません。先行する無条件の節だけで覆われる到達不能な節は `W1003` の警告です。定数の同一性は通常の比較と同じで、浮動小数点の正負のゼロも同じ値として扱います。

コンパイル時に網羅性を確認しても、防御用の実行時トラップは残します。for やラムダ式の引数の分解パターンは網羅性検査の対象ではなく、不一致時にトラップします。

## 借用と move

所有するレコード・タプル・union の非 Copy 部分を束縛すると move できます。参照先やコレクション要素を照合する場合は読み取り専用ビューとなり、元の領域から所有権を持ち去れません。

`as` で全体を束縛した場合も、非 Copy な全体とその一部を両方消費することはできません。ビューの参照を節の外へ返すことも禁止します。

Copy の束縛には必要な独立コピーが作られます。共有借用の match があらゆるコピーをなくす、という意味ではありません。

## 関数ガード

```tsuzuri run=42
def maximum :: i64 -> i64 -> i64 = \left right ->
    | left > right -> left
    | otherwise -> right

maximum 20 42
```

ラムダの `->` の直後に節を並べられます。bool 条件の節、または `pattern when condition -> result` の形式を使います。従来の `fn name 引数` に `=` を付けず節を並べる形式も使えます。

パターンは直前のラムダの引数へ照合します。一引数ならその値、`\left right ->` のような複数引数なら引数のタプルです。bool 条件だけの場合は引数のタプルを新たに構成しません。所有権と網羅性は通常の match と同じで、条件だけなら最後に無条件の節が必要です。

### where による共通の束縛

```tsuzuri run=圧勝
def judgeScore :: i32 -> i32 -> string = \left -> \right ->
    | diff > 10 -> "圧勝"
    | diff > 5 -> "接戦"
    | otherwise -> "互角"
    where
        diff = Int.abs (left - right)

judgeScore 30 10
```

`where` は省略可能です。`|` と同じインデントの独立した行に置き、その下に一つ以上の `名前 = 式` を、より深い同じインデントで並べます。`let` は付けません。`名前: 型 = 式` の型注釈も使えます。整数の絶対値は `Int.abs` です。無修飾の `abs` は `f64` 専用です。

束縛はそのラムダの本体に入ったとき、最初のガードを調べる前に上から順に一度ずつ評価します。遅延評価ではなく、選ばれた節が使わない値も評価します。引数・外側の値・先行する `where` の束縛を参照でき、すべてのガードと結果式から利用できます。後続の束縛や節のパターン変数は参照できません。

束縛のスコープはこのガード本体だけです。型推論・move・借用・寿命は通常のローカル `let` と同じです。`where` はこの位置だけで意味を持つ文脈キーワードで、ほかの位置の識別子を予約しません。

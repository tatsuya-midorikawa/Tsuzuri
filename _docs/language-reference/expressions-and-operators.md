# 式、演算子、評価順序

[ドキュメントのトップ](../README.md)

Tsuzuri は厳格評価の式指向言語です。ブロックの最後の式が値になり、評価順序とトラップを最適化で暗黙に変更しません。

## ブロックの結果

```tsuzuri run=42
def calculate :: i64 -> i64 = \value -> {
    let adjusted = value + 1;
    let adjusted = adjusted * 2;
    adjusted
}

calculate 20
```

同名の新しい束縛は以前の束縛を隠します。右辺は新しい名前を導入する前に評価するため、上の二つ目の adjusted は最初の adjusted を読めます。

最後の結果に `;` を付けると値を捨てます。最後の結果がないブロックは unit です。インデント本体の中間式には unit が必要です。

## 優先順位

低いものから順に示します。`**` は右結合、そのほかの二項演算子は左結合です。

| 順位 | 演算子・操作 |
| --- | --- |
| 1 | `\|>` |
| 2 | 関数合成 `>>`, `<<` |
| 3 | `\|\|` |
| 4 | `&&` |
| 5 | ビット OR `\|\|\|`, `\|` |
| 6 | ビット XOR `^^^`, `^` |
| 7 | ビット AND `&&&`, `&` |
| 8 | `==`, `!=` |
| 9 | `<`, `<=`, `>`, `>=` |
| 10 | シフト `<<<`, `>>>` |
| 11 | `+`, `-` |
| 12 | `*`, `/`, `%` |
| 13 | べき乗 `**` |
| 14 | `as Type` |
| 15 | 単項 `-`, `+`, `!`, `~~~`, `~`、借用・参照外し |
| 16 | 関数適用、`.field`、`[index]` |

代入 `=` はすべての二項演算より低い優先順位です。型の矢印は右結合であり、上の式の二項演算とは別です。曖昧に見える式は括弧で意図を示してください。

## 演算子の一覧

```tsuzuri run=42
let add_one = \x -> x + 1
let times_ten = \x -> x * 10
let forward = add_one >> times_ten
let backward = add_one << times_ten
assert (forward 1 == 20)
assert (backward 1 == 11)
assert (2 ** 3 ** 2 == 512)
assert (-2 ** 2 == 4)
assert ((6 &&& 3 ||| 8) == 10)
assert (~~~0 == -1)
assert (+5 == 5)
assert (not false && (true |> not |> not))
let total = [1, 2, 3]
    |> Array.sum
total * 7
```

- 単項 `+x` は数値をそのまま返し、単項 `-x` は符号を反転します。単項演算子は `**` より強く結合するので、`-2 ** 2` は `(-2) ** 2` です。
- `**` はべき乗で、`2 ** 3 ** 2` は `2 ** 9` です。整数・f32・f64・bigint に使え、組み込みクラス `Pow` に対応します（[数値](numbers.md#整数演算)）。
- ビット演算は F# と同じ `&&&`、`|||`、`^^^`、`~~~` です。従来の `&`、`|`、`^`、`~` も同じ演算の別名として受理します。
- `<<<` は左シフト、`>>>` は右シフトです。`>>>` は符号付き整数では算術、符号なし整数では論理シフトです。
- `f >> g` は `\x -> g (f x)`、`f << g` は `\x -> f (g x)` の関数合成です。`>>` / `<<` はシフトではありません。
- `not` は `bool -> bool` の組み込み関数で、`not ready` や `ready |> not` と書けます。`!` も同じ否定です。
- `ignore` は引数を捨てて `()` を返す `'a -> unit` の組み込み関数です（`value |> ignore`）。
- `@checked` を付けた式・文では、整数の `+`、`-`、`*`、`**` と単項 `-` がオーバーフローすると `OverflowException` を送出します（[例外処理](error-handling.md)）。

行頭が `|>`、`>>`、`<<`、`||`、`&&` の行は、前の行の式の続きです。上の `total` は `[1, 2, 3] |> Array.sum` です。ほかの演算子で式を続ける場合は、演算子の直後で改行します。

## 評価順序

| 構造 | 順序 |
| --- | --- |
| 通常の二項演算 | 左、右 |
| 関数呼び出し | callee、その段階の各引数を左から右 |
| パイプ `value \|> transform` | value、transform、その後適用 |
| 配列・リスト | 要素を記述順に一度ずつ |
| レコード初期化 | フィールドの記述順。宣言順へ並べ替えない |
| 代入 | 右辺、代入先 |
| レコード更新 | 元値、更新値を記述順にすべて評価、構築、旧値の解放 |
| スライス | 元配列、開始、終了 |

カリー化の途中で本体を実行する関数では、その段階の処理を後続引数より先に実行します。callee が捕捉環境を持つ場合にも、その時点のスナップショットの意味を保ちます。

## 短絡

```tsuzuri run=42
let safe = false && (1 / 0 == 0)
let available = true || (1 / 0 == 0)
assert (!safe && available)
42
```

`&&`、`||`、if の未選択分岐は必要な部分だけを評価します。一方、通常の関数は厳格評価です。例えば `default_value fallback option` の fallback は、使われなくても先に評価されます。

値を捨てる束縛、未使用の結果、length の取得なども、必要な引数の評価やトラップを省略するという言語上の指示ではありません。

## 演算子と型クラス

加算は Add、比較は Eq / Ord、ビット演算は Bits などに対応します。同名関数のオーバーロードによる探索ではありません。型の組み合わせが合わない場合、暗黙変換で合わせることはありません。

比較は共有借用で非消費、通常の算術・文字列連結は値を受け取ります。この違いは独自インスタンスでも守る必要があります。

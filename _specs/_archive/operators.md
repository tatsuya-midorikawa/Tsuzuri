# 演算子

## 単項算術演算子

| 単項算術演算子 | 説明 | 注記 | 例 |
| --- | --- | --- |
| `+` | 正 | 任意の算術式に適用できます。 値の符号を変更しません。| `let a = +1` |
| `-` | 負 | 任意の算術式に適用できます。 値の符号を変更します。| `let a = -1` |


## 二項算術演算子

| 二項算術演算子 | 説明 | 例 |
| --- | --- | --- |
| `+` | 加算 | `let a = 1 + 1  // a: 2` |
| `-` | 減算 | `let a = 1 - 1  // a: 0` |
| `*` | 乗算 | `let a = 2 * 3  // a: 6` |
| `/` | 除算 | `let a = 5 / 3  // a: 1` |
| `%` | 剰余算 | `let a = 5 % 3  // a: 2` |
| `**` | 指数、冪乗 | `let a = 2**5 // a: 32` |

### チェックされた算術演算子

特定の算術演算の前に `@checked` 属性を指定することで、算術演算のオーバーフローまたはアンダーフローの計算が検証され、重要なアプリケーションに対してより安全な算術演算が提供されます。

| 二項演算子 | 説明 | 注記 |
| --- | --- | --- |
| `+` | 加算 | 結果が最大値を超えた場合、または型でサポートされている最小値を下回った場合に、 OverflowException をスローします。 オーバーフローとアンダーフローの両方が可能です。 |
| `-` | 減算 | 結果が最大値を超えた場合、または型でサポートされている最小値を下回った場合に、 OverflowException をスローします。 オーバーフローとアンダーフローの両方が可能です。 |
| `*` | 乗算 | 結果が最大値を超えた場合、または型でサポートされている最小値を下回った場合に、 OverflowException をスローします。 オーバーフローとアンダーフローの両方が可能です。 |
| `**` | 指数、冪乗 | 結果が最大値を超えた場合、または型でサポートされている最小値を下回った場合に、 OverflowException をスローします。 オーバーフローとアンダーフローの両方が可能です。 |


```tz
def safe_add :: i32 -> i32 -> Result<i32, 'E> 
  @'E : Err = \x y -> 
    try
      @checked
      let result = x + y
      do! IO.writeln $"Result: {result}" |> ignore
      result
    with
    | e is OverflowException ->
      do! IO.writeln $"Overflow occurred: {e.msg}" |> ignore
      e

safe_add 2147483647 1

// Output:
// Overflow occurred: Arithmetic operation resulted in an overflow.
```

### 二項比較演算子

| 二項比較演算子 | 説明 | 例 |
| --- | --- | --- |
| `==` | 等値 | `let b = 1 == 1  // true` |
| `>` | より大きい | `let b = 1 > 1  // false` |
| `<` | より小さい | `let b = 1 < 1  // false` |
| `>=` | 以上 | `let b = 1 >= 1  // true` |
| `<=` | 以下 | `let b = 1 <= 1  // true` |
| `!=` | 等しくない | `let b = 1 != 1 // false` |

### bool 演算子

bool 型にのみ利用できる演算子。ブール型の AND 演算子と OR 演算子は 、短絡評価をします。

| bool演算子 | 説明 | 例 |
| --- | --- | --- |
| `not` | ブール否定 | `let b = not true  // false` |
| `||` | ブール値 OR | `let b = true || false  // true` |
| `&&` | ブール値 AND | `let b = true && false  // false` |

### bit 演算子

| bit 演算子 | 説明 |
| --- | --- |
| `&&&` | ビットごとの AND 演算子。 両方のソース オペランドの対応するビットが 1 の場合にのみ、結果のビットの値は 1 になります。 |
| `|||` | ビットごとの OR 演算子。 ソース オペランドの対応するビットのいずれかが 1 の場合、結果のビットの値は 1 になります。 |
| `^^^` | ビットごとの排他的 OR 演算子。 結果のビットは、ソース オペランドのビットの値が等しくない場合にのみ、値 1 になります。 |
| `~~~` | ビットごとの否定演算子。 これは単項演算子であり、ソース オペランド内のすべての 0 ビットが 1 ビットに変換され、1 ビットすべてが 0 ビットに変換される結果が生成されます。 |
| `<<<` | ビットごとの左シフト演算子。 結果は、2 番目のオペランドのビット数だけ左にシフトされたビットを持つ最初のオペランドです。 最上位の位置からシフトされたビットは、最下位位置には回転されません。 下位ビットにはゼロが埋め込まれます。 2 番目の引数の型は i32。 |
| `>>>` | ビットごとの右シフト演算子。 結果は、2 番目のオペランドのビット数だけ右にシフトされたビットを持つ最初のオペランドです。 最下位位置からシフトしたビットは、最も重要な位置に回転されません。 符号なし型の場合、最上位ビットはゼロで埋め込まれます。 負の値を持つ符号付き型の場合、最上位ビットは 1 つで埋め込まれます。 2 番目の引数の型は i32。 |

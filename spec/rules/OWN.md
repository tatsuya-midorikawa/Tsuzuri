# OWN: Ownership

The rules of this area, one sentence each, with the document that states them and the conformance tests that check them (`tests/conformance/OWN/`). See `spec/README.md` for the format.

| OWN-004 | Passing an owned value to a `ref T` parameter MUST borrow it implicitly without moving it. | [language.md § 呼び出し引数の暗黙の借用](../../docs/language.md#呼び出し引数の暗黙の借用) | OWN-004-passing-owned-value-to | active |

# OWN: Ownership

The rules of this area, one sentence each, with the document that states them and the conformance tests that check them (`tests/conformance/OWN/`). See `spec/README.md` for the format.

| ID | Rule | Doc | Tests | Status |
| --- | --- | --- | --- | --- |
| OWN-001 | A `let` binding from a non-Copy value (such as a `string`) MUST move the value, and a later read of the source binding MUST be rejected with E1012. | [language.md § Ownership / Borrowing](../../docs/language.md#ownership--borrowing) | OWN-001-let-binding-from-non | active |
| OWN-002 | A `let` binding from a Copy value (such as an `i64`) MUST NOT move the source, so both bindings stay readable. | [language.md § Ownership / Borrowing](../../docs/language.md#ownership--borrowing) | OWN-002-let-binding-from-copy | active |
| OWN-003 | Passing a non-Copy value to a by-value parameter MUST move it into the callee; a later read in the caller MUST be rejected with E1012. | [language.md § Ownership / Borrowing](../../docs/language.md#ownership--borrowing) | OWN-003-passing-non-copy-value | active |
| OWN-004 | Passing an owned value to a `ref T` parameter MUST borrow it implicitly without moving it. | [language.md § 呼び出し引数の暗黙の借用](../../docs/language.md#呼び出し引数の暗黙の借用) | OWN-004-passing-owned-value-to | active |
| OWN-005 | Any number of shared borrows (`ref T`) of the same owner MAY be live at the same time. | [language.md § Ownership / Borrowing](../../docs/language.md#ownership--borrowing) | OWN-005-any-number-of-shared | active |
| OWN-006 | An exclusive borrow (`ref mut T`) MUST be rejected with E1014 while a shared borrow of the same owner is still used later. | [language.md § Ownership / Borrowing](../../docs/language.md#ownership--borrowing) | OWN-006-exclusive-borrow-ref-mut | active |
| OWN-007 | A borrow MUST end after its last use, so the owner is usable again afterwards. | [language.md § Ownership / Borrowing](../../docs/language.md#ownership--borrowing) | OWN-007-borrow-must-end-after | active |
| OWN-008 | A value moved on any path MUST NOT be used after the paths join (E1012). | [language.md § Ownership / Borrowing](../../docs/language.md#ownership--borrowing) | OWN-008-value-moved-on-any | active |
| OWN-009 | Moving one field out of a record MUST leave the other fields usable. | [language.md § Ownership / Borrowing](../../docs/language.md#ownership--borrowing) | OWN-009-moving-one-field-out | active |
| OWN-010 | Moving a non-Copy value out through a reference MUST be rejected with E1012. | [language.md § 呼び出し引数の暗黙の借用](../../docs/language.md#呼び出し引数の暗黙の借用) | OWN-010-moving-non-copy-value | active |

| OWN-012 | A user-declared record without `Drop` whose fields are all Copy MUST be Copy, so a `let` from it does not move. | [language.md § Ownership / Borrowing](../../docs/language.md#ownership--borrowing) | OWN-012-record-whose-fields-are | active |
| OWN-013 | A record with a non-Copy field MUST NOT be Copy, so a `let` from it moves. | [language.md § Ownership / Borrowing](../../docs/language.md#ownership--borrowing) | OWN-013-record-with-non-copy | active |
| OWN-014 | A function MUST NOT return a reference to a local owner (E1013). | [language.md § Ownership / Borrowing](../../docs/language.md#ownership--borrowing) | OWN-014-function-must-not-return | active |
| OWN-015 | Moving a value inside a loop body MUST be rejected when the value is used again in a later iteration (E1012). | [language.md § for / while](../../docs/language.md#for--while) | OWN-015-moving-value-inside-loop | active |
| OWN-016 | Two exclusive borrows of the same owner MUST NOT be live at once (E1014). | [language.md § Ownership / Borrowing](../../docs/language.md#ownership--borrowing) | OWN-016-two-exclusive-borrows-of | active |
| OWN-017 | A function taking `ref mut T` MUST be able to update the caller's `let mut` owner through `deref`. | [language.md § Ownership / Borrowing](../../docs/language.md#ownership--borrowing) | OWN-017-function-taking-ref-mut | active |
| OWN-018 | The `+` operator on two strings MUST consume its left operand. | [language.md § string と utf8string](../../docs/language.md#string-と-utf8string) | OWN-018-operator-on-two-strings | active |
| OWN-019 | A shared reference `ref T` MUST be Copy, so one reference MAY be bound to several names. | [language.md § Ownership / Borrowing](../../docs/language.md#ownership--borrowing) | OWN-019-shared-reference-ref-t | active |
| OWN-020 | A shared borrow MUST prevent moving its owner while the borrow is still used later (E1014). | [language.md § Ownership / Borrowing](../../docs/language.md#ownership--borrowing) | OWN-020-shared-borrow-must-prevent | active |
| OWN-021 | Assigning to an owner MUST be rejected while a borrow of it is still used later (E1014). | [language.md § Ownership / Borrowing](../../docs/language.md#ownership--borrowing) | OWN-021-assigning-to-owner-must | active |
| OWN-022 | A variable moved in a loop MUST be usable again after it is assigned a new value before the next iteration. | [language.md § for / while](../../docs/language.md#for--while) | OWN-022-variable-moved-in-loop | active |
| OWN-023 | A `Drop` instance MUST run once when the owner leaves its scope, and owners MUST be dropped in reverse order of declaration. | [language.md § 利用者定義の解放（Drop）](../../docs/language.md#利用者定義の解放drop) | OWN-023-drop-instance-must-run | active |
| OWN-024 | A value moved to another owner MUST NOT be dropped by its original owner. | [language.md § 利用者定義の解放（Drop）](../../docs/language.md#利用者定義の解放drop) | OWN-024-value-moved-to-another | active |
| OWN-025 | Assigning a new value to a `let mut` owner MUST drop the old value immediately. | [language.md § 利用者定義の解放（Drop）](../../docs/language.md#利用者定義の解放drop) | OWN-025-assigning-new-value-to | active |
| OWN-026 | A type with a `Drop` instance MUST NOT be Copy, so a `let` from it moves. | [language.md § 利用者定義の解放（Drop）](../../docs/language.md#利用者定義の解放drop) | OWN-026-type-with-drop-instance | active |
| OWN-027 | User code MUST NOT call `Drop.drop` directly (E1016). | [language.md § 利用者定義の解放（Drop）](../../docs/language.md#利用者定義の解放drop) | OWN-027-user-code-must-not | active |
| OWN-028 | A reference MUST NOT be bound to a `let` with a `ref` annotation by implicit borrowing; implicit borrowing applies to call arguments only. | [language.md § 呼び出し引数の暗黙の借用](../../docs/language.md#呼び出し引数の暗黙の借用) | OWN-028-reference-must-not-be | active |
| OWN-029 | Passing a reference to a parameter that takes a non-Copy value by value MUST be rejected (E1012). | [language.md § 呼び出し引数の暗黙の借用](../../docs/language.md#呼び出し引数の暗黙の借用) | OWN-029-passing-reference-to-parameter | active |
| OWN-030 | A tuple that contains a non-Copy element MUST NOT be Copy, so a `let` from it moves. | [language.md § Ownership / Borrowing](../../docs/language.md#ownership--borrowing) | OWN-030-tuple-that-contains-non | active |
| OWN-031 | The key components of an index expression MAY read its base but MUST NOT assign, move or exclusively borrow it (E1014). | [language.md § 式と評価順序](../../docs/language.md#式と評価順序) | OWN-031-index-key-cannot-change-base | active |

| OWN-033 | While evaluating the right-hand side `e` of a compound assignment `p op= e`, `e` MAY read `p` but MUST NOT assign to, move, or exclusively borrow `p` (E1014). | [language.md § 式と評価順序](../../docs/language.md#式と評価順序) | OWN-033-compound-assignment-guards-target-during-rhs | active |
